## Firecrawl (`lib/firecrawl/*`)
- `client.ts`: `new Firecrawl({ apiKey })` (v2 SDK, `.scrape(url, { formats: [{ type: 'json', schema }] })`).
- `rate-limiter.ts`: promise queue `RateLimiter(concurrency, delayMs)`.
- `trustpilot.ts`: `scrapeTrustpilotBusiness(url)` — JSON-schema extraction: displayName, websiteUrl, phone, email, locationCity, locationCountry, categories[] (0 → category, 1 → subcategory), numberOfReviews, stars, trustScore, relatedBusinessSlugs[], socialLinks {facebook, twitter, linkedin, instagram}, numberOfVisibleReviews, oldestVisibleReviewDate; logo = `https://t1.gstatic.com/faviconV2?client=SOCIAL&type=FAVICON&fallback_opts=TYPE,SIZE,URL&url=https://{slug}&size=128`; upsert on trustpilot_id; velocity; relations only to slugs already in DB. `scrapeTrustpilotCategory(url, max=50)`: pages `?page=N`, 20/page, 1 concurrent 1.5 s apart, extracts name/slug/stars/reviews/location, inserts basic rows (`last_scraped_at` null).
- `bfs-crawler.ts` (unused), `enrichment.ts` (`enrichBusiness(id)`: scrape own website for phone/email/socials).
- Cron: `sync-businesses` daily (12 stale rows, 30 s budget, `after()` self-chain depth 3), `seed-categories` weekly (22 categories, `lib/constants.ts` CATEGORY_URLS).
- Env: FIRECRAWL_API_KEY, NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY, CRON_SECRET, NEXT_PUBLIC_APP_URL.
