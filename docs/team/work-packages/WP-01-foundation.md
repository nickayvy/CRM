# WP-01: Foundation — scaffold, schema, data layer, shell, seed

**Wave:** 1
**Depends on:** none
**Owns files:** everything in the repo except `docs/team/**` and `.claude/**` (this is the first package; later packages take ownership of the paths listed in `docs/team/architecture.md` §Components)
**Delivers:** branch `wp-01-foundation` / PR titled "WP-01: Foundation"

## Objective
A runnable Next.js app with the complete database schema and migrations,
a client that uses PGlite with no config and Supabase Postgres when
`DATABASE_URL` is set, a test harness, realistic fixtures and an
idempotent seed, the app shell with navigation to every top-level route
(placeholders), an optional password gate, and deploy configuration.
When this merges, three packages start in parallel on top of it.

  businesses; 2 call campaigns (one `running` with 25 queue items, 5 of

  3 steps and 8 enrollments (businesses with emails), 4 `dry_run`

- App shell: `src/app/layout.tsx` (fonts, `ThemeProvider`, `Toaster`),

## Acceptance criteria
AC-01.1 Clean clone, no env vars: `npm ci && npm run db:migrate && npm run db:seed && npm test && npm run typecheck && npm run lint && npm run build` all exit 0. Proof: paste the tail of each.
AC-01.2 `npm run dev` then `curl -s -o /dev/null -w '%{http_code}'` for `/`, `/businesses`, `/searches`, `/calling`, `/email`, `/settings`, `/design`, `/login` → 200 each; the shell nav contains all six links (grep the HTML).
AC-01.3 With `APP_PASSWORD=secret npm run dev`, `curl -I /businesses` → 307/302 to `/login`; posting the password sets a cookie and `/businesses` → 200 with it.
AC-01.4 `tests/db.test.ts` proves seed idempotency; the seed summary printed by `npm run db:seed` lists every table with its count; `businesses` = 100 (40+30+30), `call_campaigns` = 2, `call_queue_items` = 25, `email_steps` = 3, `email_enrollments` = 8.
AC-01.5 `fixtures/yelp/search-plumbing-houston.json` contains the eleven named trap records with exactly the attributes in architecture §Fixture traps (names, is_closed, phone, rating, review_count, distance, categories, city), and "ABC Plumbing" exists in all three fixtures with distinct ids and cities. Proof: a test `tests/fixtures.test.ts` asserts these.
AC-01.6 `DATABASE_URL` path: with a Postgres URL set, `getDb()` uses postgres-js (unit test may stub; at minimum `npm run typecheck` covers the branch and README documents it). The migrator runs the same `drizzle/` folder for both drivers.
AC-01.7 At 375 px, `/businesses` placeholder shows the mobile nav trigger and no horizontal scroll (screenshot path in report).
AC-01.8 `.env.example`, `vercel.json`, `README.md` exist with the contents described above.
